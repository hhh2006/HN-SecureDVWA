# Security Policy

HN SecureDVWA is an educational defensive-security project derived from the DVWA environment used in a controlled local laboratory.

## Supported scope
Security hardening and regression testing of the modified local application.

## Responsible use
Do not use the included attack techniques against systems you do not own or lack explicit authorization to test.

## Reporting
For this educational repository, security issues should be documented with the affected component, reproducible local-lab steps, observed impact, and proposed remediation. Do not include real credentials, secrets, session tokens, or personal data.
