# SecureDVWA V3.10.1 — Mouse Tracking Removal

## Change

V3.10.1 removes all custom mouse/pointer movement tracking from the cinematic UI.

- Removed card `pointermove` 3D tilt interaction.
- Removed dashboard hero `pointermove` 3D tracking.
- Removed pointer-coordinate based ripple placement; ripples now originate from the button center.
- Removed dynamic pointer-position CSS variables from the cinematic glow layer.
- Preserved normal browser mouse/touch interaction such as click, focus, navigation, and scrolling.
- Preserved autonomous visual animations and cinematic HUD effects.

## Verification

A project-wide source scan reports no `pointermove`, `mousemove`, `clientX`, `clientY`, `movementX`, `movementY`, `--pointer-x`, or `--pointer-y` tracking code in the release source.

Regression and release checks pass.
