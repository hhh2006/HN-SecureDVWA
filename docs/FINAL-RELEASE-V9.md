# SecureDVWA V9 — Presentation & Demo Edition

V9 adds a guided presentation layer while retaining real database telemetry.

## Highlights
- Robust sidebar reopen control and independently scrollable module navigation.
- Presentation Mode from the header or `D` shortcut.
- Five-stage guided flow: Command Center → Threat Intelligence → Risk Assessment → Assurance → Executive Report.
- Security Center quick action.
- Animated, responsive presentation overlay with reduced-motion support.
- Presentation Mode never fabricates security events or attack results.

## Validation boundary
Automated checks do not replace the final local XAMPP browser run and genuine academic evidence capture.
